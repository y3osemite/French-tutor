# 🇫🇷 Mon Tuteur Français

A personal French tutor app for Inspire 1 A1.2 students preparing for DELF A1.

🔗 **Live app:** https://french-tutor-psi.vercel.app

## About
- Built for Inspire 1 textbook (Le Bougnec & Lopes)
- Covers Leçons 14–21
- 20-minute daily practice sessions
- Supports Korean, Spanish, Italian and Greek speakers
- Upload your class PDF and the tutor anchors the session to it

## Tech
- Plain HTML + React (via CDN)
- Vercel serverless function for secure API calls
- Anthropic Claude API
